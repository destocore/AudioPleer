# 🎶 AudioPleer — веб-проигрыватель музыки

**AudioPleer** — это легкий веб-сервис на базе Django, созданный для удобного хранения и воспроизведения вашей музыкальной коллекции.

# 🚀 Основные фишки

*   **Умный проигрыватель:** Три режима циклов: без повтора, повтор всего списка или повтор одного трека.
*   **Регулировка громкости:** Удобный ползунок для изменения громкости прямо в интерфейсе сайта.
*   **Управление треком:** Интуитивная перемотка с помощью таймлайна, кнопки переключения и паузы.
*   **Минималистичный дизайн:** Чистый интерфейс с фокусом на юзабилити.

# 🛠 Технологии

*   **Язык:** Python 3.10+ (рекомендуется 3.13.3)
*   **Фреймворк:** Django 6.0.0+ (рекомендуется 6.0.5)
*   **Установщик .mp3 аудио с площадок:** pytubefix 10.7.0+ (YouTube | рекомендуется 10.7.2)
*   **База данных:** SQLite (встроенная)
*   **Фронтенд:** HTML5, CSS3 (Custom Styles)

# ⚙️ Настройки

Все настройки доступны в `AudioPleer/settings.py`

*   `AUTO_UPGRADE_CHECK` — авто-проверка обновлений (True/False)
---
*   `EXPORT` — настройки экспорта музыки
* ⌊`status` — экспорт музыки (True/False)
* ⌊`cache_mus` — сохранять готовый архив на сервере для моментальной отдачи без пересборки (True/False)
---
*   `ALLOW_DEL` — разрешение на удаление файлов из `media/music/`
* ⌊`mus` — разрешить удалять музыки (True/False)
* ⌊`playlist` — разрешать удалять плейлисты (True/False)

`⚠️ **ВАЖНО!**: Все удалённые файлы с помощью сайта нельзя будет восстановить обычным путём (через корзину)`

---

*   `ALLOW_REN` — разрешение на переименования файлов из `media/music/`
* ⌊`mus` — разрешить переименовать музыку (True/False)
* ⌊`playlist` — разрешать переименовать плейлисты (True/False)

---

*  `ALLOW_REPM` - разрешение на перемещения музыки из `media/music/`

---
# 📂 Добавление музыки

Файлы с музыкой хранятся в папке: `media/music/`

Просто скопируйте туда свои аудиофайлы в формате **.mp3**.

# 📂 Добавление плейлиста

Все плейлисты хранятся в папке `media/music/` с любым именем папки

---

# 🌐 Доступные URL-адреса

*   `/` — главная страница плеера.
*   `/download` — Установщик аудио с других площадок (youtube) [! можно писать несколько ссылок через пробел]
*   `/playlist/<название плейлиста>` — плейлист

# 🔧 Как запустить локально

## Windows

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/destocore/AudioPleer.git
   cd AudioPleer
   ```
2. Установите зависимости:
   ```bash
   pip install -r pip.txt
   ```
3. Примените миграции БД:
   ```bash
   python manage.py migrate
   ```
4. Запустите сервер (через батник или через команду):
   ```bash
   waitress-serve --listen=0.0.0.0:80 AudioPleer.wsgi:application
   ```
5. Откройте в браузере: `http://127.0.0.1:80`

## Linux / macOS / BSD

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/destocore/AudioPleer.git
   cd AudioPleer
   ```
2. Установите зависимости:
   ```bash
   pip3 install -r pip.txt
   ```
3. Примените миграции БД:
   ```bash
   python3 manage.py migrate
   ```
4. Запустите сервер (через .sh скрипт или через команду):
   ```bash
   sudo waitress-serve --listen=0.0.0.0:80 AudioPleer.wsgi:application
   ```
5. Откройте в браузере: `http://127.0.0.1:80`

## Docker

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/destocore/AudioPleer.git
   cd AudioPleer
   ```
2. Соберите контейнер:
    ```bash
    docker build -t audiopleer .
    ```
3. Запустите контейнер:
    ```bash
    docker run -p 80:80 audiopleer
    ```
4. Откройте в браузере: `http://127.0.0.1:80`
